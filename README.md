# ZanJewelry Luxe Store

Fresh premium storefront prototype for a new jewellery, skincare and gift-set business.

## Open the site

Open `index.html` in a browser. No build step is required.

## Included

- Home page with dark editorial header and full-width lifestyle hero
- Shop with Jewellery, Skincare and Gift Sets filters
- Shop-by-gemstone / diamond type grid
- Product detail modal pages with hash URLs
- Cart drawer with quantity controls and checkout placeholder
- Admin dashboard for adding/editing products, prices, photos and stock in browser storage
- Bespoke jewellery request flow
- Ring size guide
- Gift sets, reviews, story and contact sections
- Basic SEO title and meta description

## Production notes

For a real launch, connect checkout to a South African payment provider such as PayFast, Peach Payments, Yoco or Ozow, then add Payflex or PayJustNow for buy-now-pay-later. The admin dashboard in this prototype saves to local browser storage; production should use Shopify, WooCommerce, Medusa, Sanity, Supabase or another secure back office.
